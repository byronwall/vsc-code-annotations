# Support

If the extension behaves unexpectedly:

- Include the VS Code version, extension version, operating system, and the annotation entry or workspace state that reproduces the problem.
- If this repo is published, open an issue in the host repository. If it is still local-only, capture the reproduction details in the annotations document or project notes.

For local debugging, run:

```bash
pnpm install
pnpm run compile
pnpm run dev:host
```
